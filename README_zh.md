# 桥牌演示工具

这是一个基于 Python、PyQt6 和 SQLite 的桌面应用程序，可用于管理桥牌牌例和场景、配置出牌规则并演示牌局。

## 功能

- 管理员可以注册、登录和退出；管理员密码以哈希形式保存。
- 使用资源树组织文件夹、牌例、牌局和场景，并支持搜索、上下文菜单、快捷键、复制和重命名。可用“全部展开”/“全部折叠”和 Ctrl/Cmd + +/−/0 管理当前资源树。
- 可在有效的父级位置之间移动文件夹、牌例、牌局和场景。移动前会预览来源与目标并要求确认；移动父级时其子资源也会一并移动。
- 使用 PBN 输入或可视化选牌器创建牌局。选牌器可校验 52 张牌并随机分配剩余牌。
- 为场景设置叫牌过程、定约、庄家、加倍状态、标签或目标序列。
- 在桥牌桌上演示场景，使用隐藏视图控制牌面信息，并查看双明手分析结果。
- 测试由多个题目组成。每题可包含同一牌例中的多个候选场景；每次测试只随机选择其中一个场景。
- 管理员可为每个测试场景单独设置可接受定约和结果墩差的分数，即使不同场景的定约相同也会分别评分。
- 管理员可以注册学生、分配测试并查看提交结果。学生登录后自动进入锁定模式，只能运行已分配且尚未完成的测试；每个分配只能完成一次。
- 可将管理员工作区导出为单个加密 `.bdtpack` 文件，并在另一台电脑上导入。数据使用 scrypt 派生密钥和 AES-256-GCM 认证加密；导入使用事务并追加到当前管理员账户，不会导出管理员登录凭证。
- 可生成管理员名下的测试报告，包含成绩统计、考生-题目矩阵、场景难度统计和前三名，并可导出为中英文 PDF。
- 使用可选的 `dds3` 模块和机器人代理执行 DDS 分析及自动出牌。

## 场景工作流

牌桌显示的是场景，而不是牌局：

1. 在资源树中选择牌局不会自动将其载入牌桌。
2. 选中牌局后添加资源会创建一个空场景并载入牌桌。
3. 新场景初始没有叫牌、标签或目标牌序列。请在开始演示前使用牌桌控件配置场景。
4. 单击场景只会选择它；双击场景会先保存当前场景，再载入所选场景。
5. 退出管理员账户前，当前场景会保存叫牌、定约、庄家、加倍状态、标签、目标模式和目标牌序列。

可进行出牌的场景必须具有完整且合法的叫牌过程和有效定约。标签规则可以不设置标签；没有标签时，机器人只使用 DDS 推荐。目标规则则必须有目标出牌序列。流局不开始出牌演示。

使用中央的**叫牌**按钮编辑叫牌过程或查看场景信息。**管理员**菜单现在位于**偏好设置**菜单之前。偏好设置菜单包含 DDS、样式、机器人、音效和视图选项。DDS 菜单控制矩阵显示及墩数格式；样式菜单可调整牌张大小、牌面花色符号大小、应用字体大小（10–24 像素）、字体颜色和背景颜色，也可调整资源树宽度、上方区域高度、中央区域高度及各区域背景色；机器人菜单控制出牌间隔以及跟随目标序列或标签；独立的音效菜单可开关出牌音效并调整音量；视图菜单可切换分析视图和隐藏视图，并旋转桌面。颜色标签定义与编辑器位于**资源管理器 > 标签**，并按每个出牌阶段的颜色优先顺序显示。管理员偏好会自动保存，并在登录时恢复。测试回放固定使用 43 像素牌宽、1200 毫秒机器人间隔和 50% 音量；叫牌菜单只显示只读叫牌路线、不显示叫牌矩阵，但仍可打开场景信息；上一步、重置、下一步和人类座位控制会隐藏。

中央**叫牌**窗口会将叫牌过程和叫牌矩阵居中显示；矩阵列顺序为无将、黑桃、红心、方块、梅花，行顺序为 1 到 7 阶。无将叫品显示为灰色，黑桃显示为深蓝色，其他花色使用各自的颜色；叫牌路线也会显示相同的花色颜色。

**分析/隐藏视图**用于切换信息可见性。隐藏视图中，牌张不可见时会直接隐藏，不会显示牌背。点击单个**开始/结束**按钮可开始或停止演示。演示期间标签不可见；演示或测试期间仍可打开叫牌内容。记录序列演示中可使用“下一步”，标签演示中则禁用该按钮。记录目标控件在演示期间保持禁用。加倍状态根据叫牌过程自动计算。目标序列演示会让机器人按记录顺序自动出牌；标签演示由机器人根据标签选择牌张。机器人每次出牌后会稍作停顿，可在**偏好设置 > 机器人**使用水平滑块调整间隔，并在**偏好设置 > 音效**开关出牌音效和调整音量。每墩已打出的牌会位于桌面中心的四个方位，并沿中心的水平线和垂直线对齐。分析视图中，当前方合法手牌的 DDS 结果以紧凑角标显示在牌面右下方。在隐藏视图中，防守方用户的手牌会显示；用户在首墩打出第一张牌后，明手才会显示。

若要记录目标序列，请在分析视图中手动完成全部 52 张牌。**记录目标**按钮会保持显示，并在加载场景且牌局完成后启用；点击后会保存序列并保留已完成的牌局。牌面底部的 DDS 结果数字已加大。标签策略的默认颜色行为与英文 README 中列出的规则一致；在**资源管理器 > 标签 > 显示标签定义**中可查看按出牌阶段和颜色排列的 3×6 矩阵，每个单元格的数字表示该颜色在对应阶段的优先顺序。

## 测试与锁定模式

管理员使用**测试 > 练习构建**创建、编辑和删除测试。每道题来自一个牌例，可加入一个或多个候选场景。合同由所选场景的最终定约生成；管理员可编辑可接受的结果墩差（例如 `=`、`-1`、`-2`、`+1`、`+2`）及对应分数。测试场景会读取原场景的叫牌、定约、加倍状态、标签和信息文本。

在**测试 > 学生管理**中，管理员可创建学生账户、分配测试或移除尚未完成的分配。学生使用**管理员 > 学生登录**输入注册时提供的学生编号和密码。登录后会自动进入锁定模式，并显示可参加的测试。学生可输入 `Run 测试名称` 开始测试；锁定会话中不能单独运行场景。每题随机运行一个候选场景，使用标签规则和隐藏视图。场景结束时会显示结果，并提供继续按钮。测试完成后会保存成绩和学生关联，并将该测试从可用列表中移除。

管理员也可进入**管理员 > 管理员锁定模式**，重新输入管理员密码。管理员锁定终端支持：

- `Run (牌局名称)场景名称`：使用目标规则和隐藏视图播放场景已记录的目标序列。
- `Run 测试名称`：运行当前管理员创建的测试。
- `Help`：查看命令。
- `Exit`：退出锁定模式并注销所有账户，返回未登录状态；无需再次输入密码。

使用**测试 > 查看测试结果**可查看当前管理员测试的提交记录。

## 菜单

- **偏好设置**：DDS、标签、样式、机器人、音效和视图选项。
- **管理员**：管理员注册、登录、退出、学生登录及管理员锁定模式。
- **管理员菜单**还提供管理员数据加密导出和导入；导出需使用独立口令，口令至少 12 个字符且无法找回。
- **工具**：监控、使用说明、语言选择和键盘快捷键。
- **测试**：测试构建、运行测试、查看测试结果和学生管理。
- **资源管理器**：打开 `README.md` 和 `requirements.txt`。界面语言为中文时，README 菜单项会打开本文件；菜单中不会重复列出中英文版本。

## 依赖与运行

- Python 3.10 或更新版本。
- `requirements.txt` 中列出的依赖（包括 PyQt6 和 cryptography）。
- 可选：与当前 Python 次版本及操作系统兼容的 `dds3` 原生扩展。

克隆项目时，请使用以下命令初始化 DDS 源码子模块：

```bash
git clone --recurse-submodules https://github.com/Jelly0200/Bridge-Demonstration-Tool.git
cd Bridge-Demonstration-Tool
```

`dds3` 不包含在 `requirements.txt` 中。若没有兼容扩展，应用仍可使用，但需要 DDS 求解器的功能不可用。

在项目根目录运行：

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m src.main
```

应用默认在当前工作目录中使用 `bridge_tool.db`。请从项目根目录启动，以便数据库保存在该目录。

运行测试：

```bash
QT_QPA_PLATFORM=offscreen python -m unittest discover -s tests -v
```

## 数据模型

`schema.sql` 定义 SQLite 数据库结构：

| 表 | 用途 |
| --- | --- |
| `Administration` | 管理员账户 |
| `Folder`、`CaseStudy`、`Board` | 管理员的资源树、牌例和牌局 |
| `BoardConfiguration` | 发牌者和局况 |
| `Scenario`、`Label` | 场景设置和有序出牌标签 |
| `Test`、`Rule`、`Test_Scenario` | 测试、评分规则及每题的场景候选 |
| `Student` | 学生姓名和加盐密码哈希 |
| `Student_Test` | 学生测试分配及一次性完成状态 |
| `Test_Result` | 测试成绩和场景结果，并关联学生账户 |

学生密码使用加盐 PBKDF2 哈希保存。迁移前产生的、没有学生关联的旧结果仍可读取。

集成的锁定测试流程使用已保存的测试并保存学生成绩。选择“测试 > 生成测试报告”可查看统计并导出 PDF。
